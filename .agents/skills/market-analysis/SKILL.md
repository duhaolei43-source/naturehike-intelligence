# market-analysis

## Required inputs
The relevant public raw records, source registry, current code/SQL/config, and research question. Use private evidence only at the external AUDIT_ROOT when needed; never publish it.

## Procedure
Build the deterministic SQL marts. Summarize convenience sample using median, range, IQR and missingness. Match season, structure, construction and accessories for gaps/frontiers; compare one weight definition. Show batch-scoped Trends only when real metadata exists. Check minimum/packed and sale-exclusion sensitivity.

## Expected outputs
Reviewed analytical tables, source-linked charts and bounded numerical findings.

## Failure conditions
Mixed normalization batches, synthetic business observations, sales inference from search indices or representative confidence claims.

## Verification
Run the relevant contract/unit/integration checks and inspect the resulting records against the source and requested scope. Record uncertainty and failed checks in the external audit ledger. Read [methodology](../../../docs/METHODOLOGY.md) and [source policy](../../../docs/SOURCE_POLICY.md) when analytical definitions or publication scope change.
