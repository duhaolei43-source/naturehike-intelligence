- **Weight messaging needs two definitions.** Cloud Up Pro 2 is displayed at \$159 versus Cloud Up 2 at \$119. The reported minimum weight falls only 20 g (1.45%), while packed weight falls 270 g (15.00%). This supports clearer specification messaging, not a measured preference for the upgrade. [Official Cloud Up](https://www.naturehike.com/products/cloud-up-2-person-ultralight-backpacking-tent), [official Pro](https://www.naturehike.com/products/cloud-up-pro-2-person-ultralight-backpacking-tent).
- **A price premium is not explained by floor area alone.** REI Half Dome 2 costs \$329 versus Trailmade 2 at \$199; both publish 31.8 ft² floor area, two doors and an included footprint. The \$130 premium (65.33%) needs richer feature evidence before a value judgment. [Half Dome](https://www.rei.com/product/243702/rei-co-op-half-dome-2-tent-with-footprint), [Trailmade](https://www.rei.com/product/243611/rei-co-op-trailmade-2-tent-with-footprint).
- **Bundled accessories need visible disclosure.** Cloud Up/Pro and REI's sampled tents include a footprint; Kelty Late Start sells it separately. Headline prices do not establish equivalent complete-kit cost. [Late Start](https://kelty.com/products/late-start-2p). These observations motivate a transparency test; no customer response has been measured.
