# Research agent instructions

This is an independent personal project, not Naturehike employment or internal analytics.
Never fabricate observations, claim business outcomes that were not measured, hide failed tests, or substitute synthetic fixtures for public evidence.
Every material claim needs a source identifier and a reproducible calculation. Distinguish observations, interpretations, hypotheses and recommendations.
Preserve UTC observation dates, variant identity, price type, units, null reasons, and source restrictions. Do not infer stock from a generic Add to Cart button.
Use official sources and maintainable libraries with least-privilege access. Do not bypass access controls or download/execute unknown skill scripts.
Maintain local private evidence outside the repository using AUDIT_ROOT or ~/Documents/ResearchVault/naturehike-us-market-intelligence. Never publish that archive, credentials, session transcripts or full copyrighted captures. Do not silently replace previous audit records.
Use feature branches and pull requests. Inspect staged filenames and diff; do not blindly stage all files, force-add ignored data, force-push or overwrite unrelated work.
Run locked install, Ruff lint/format, SQLFluff, data validation, all tests, offline reproducibility smoke, release guard and Gitleaks before release. Record failures independently and fix or disclose them. Rebuild exports after code/input changes.
Trends data require documented joint normalization scope; cross-batch comparisons are unsupported. Fixtures are TEST DATA and remain separate.
Power BI is optional. Model design and DAX are UNVERIFIED until a supported runtime has opened the report and matched reference queries.
Use the repository skills for source verification, normalization, analysis, claim audit and release review.
